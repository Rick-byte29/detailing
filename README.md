# TORQUE Detailing Studio

Responsive static, single-page car-care website for Gerukabari, Bijni, Assam.

## Run
Serve `dist` with any static server. No npm dependencies or build step required.
For Vercel use Framework Preset Other and Output Directory `dist`.

## Features
Three-second real-footage drifting-car loader, looping local detailing video with edge depth blur, scroll reveals, ten-photo CSS 3D coverflow (touch and keyboard), before/after range slider, vehicle-size pricing, WhatsApp CTAs and enquiry form, local font assets, map, FAQ and privacy dialog.

## Customisation
Brand name, copy, prices and location are in `dist/index.html`. Number is set to +91 9101035255 in `dist/app.js` and HTML. Demo testimonials are visibly labelled and prices are indicative. Replace these with verified business information before public commercial use. The map marks the requested area rather than an unverified exact business address.

## Privacy
The site has no server-side form storage or analytics. The form opens a WhatsApp message, requiring the visitor to send it. Google Maps is a third-party embed.
